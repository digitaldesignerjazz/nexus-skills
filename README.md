## What belongs here

- Public skill excerpts (roles, interfaces, proposed procedures)
- Dummy schemas and demo scripts without live credentials
- Contributor and security policy

## What does not belong here

- skilllogin dumps and `*_state.md` files
- Live overlay keys, wallet material, private ledgers
- Private persons and correspondence
- Copies of private repositories

See [docs/PUBLIC_BOUNDARY.md](docs/PUBLIC_BOUNDARY.md).
