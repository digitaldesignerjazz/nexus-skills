# Public boundary

Assume every commit is readable by strangers.

## Allowed

- Skill excerpts that describe roles and public procedures
- Proposed interfaces with dummy values
- Agent role names already used in public siblings — Lumia / Elara, Lyra, Xen, Elysium, Nyx, Orchestrator
- Operator public identity (Esslinger & Co., digitaldesignerjazz, Hannover as project origin)

## Forbidden

- Private persons and correspondence
- Household, land or family internals
- Live keys, tokens, seeds, overlay setup material
- skilllogin dumps and private ledgers
- Contents copied from private repositories
- Claims of a live public chain or activated rune set

QNET / Wizard Q / runes remain **Proposed** unless a public spec in Aether says otherwise.
