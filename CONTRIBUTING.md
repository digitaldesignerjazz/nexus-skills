# Contributing

1. Read [docs/PUBLIC_BOUNDARY.md](docs/PUBLIC_BOUNDARY.md) first.
2. Open an issue before large scope.
3. Branch from `main`. Small commits. Pull requests against `main`.
4. Do not force-push `main`.
5. Do not add secrets, private names, live configs or skilllogin files.
6. New public files default to Apache-2.0.
7. Skill `description` frontmatter must stay a single unquoted line without colon-space.

Cross-lineage policy lives in [Aether](https://github.com/digitaldesignerjazz/Aether).
